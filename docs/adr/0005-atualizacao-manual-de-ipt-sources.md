# Atualização de ipt_sources.csv via flag manual, isolada por host

Cada IPT expõe um Inventário (`inventory/v2/dataset?type=dwca`) que lista seus recursos DwC-A. Para manter `ipt_sources.csv` sincronizado sem depender de curadoria manual completa, a atualização roda como uma flag no mesmo binário (`-update-sources`), nunca acoplada à ingestão normal: a ingestão não deve falhar ou atrasar porque um dos 10 hosts de catálogo está fora do ar (caso real observado com `ipt.jbrj.gov.br` durante o design). Por host, a busca usa timeout curto (15s) sem retry — é operação manual, repetir é trivial — e falha/timeout de um host deixa as linhas daquele host completamente intocadas (nem adiciona, nem remove), evitando que uma falha de rede seja lida como "recursos despublicados". Só um host respondido com sucesso pode ter linhas removidas (tag sumiu do inventário) ou adicionadas (tag nova, `core=OCCURRENCE`). Linhas novas usam `repositorio` = último segmento do path da URL e `kingdom` em branco (a API não fornece nenhum dos dois); linhas existentes preservam `nome`/`kingdom`/`repositorio` curados à mão, mesmo que o `title` da API mude. O CSV resultante anexa recursos novos ao final do bloco de ocorrências do host, sem reordenar o restante do arquivo, para manter o diff mínimo. Uma flag `-dry-run` mostra o plano (host a host) sem gravar.
