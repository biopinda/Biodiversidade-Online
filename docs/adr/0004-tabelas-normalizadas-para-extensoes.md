# Tabelas normalizadas para extensões de táxon

A versão anterior (MongoDB) dobrava cada extensão DwC-A (distribution, vernacularName, speciesProfile, reference, typesAndSpecimen, resourceRelationship) em um campo aninhado dentro do documento `taxa`. Em um banco relacional isso viraria uma coluna JSON opaca, difícil de indexar e consultar. Optou-se por uma tabela DuckDB por extensão (`taxon_vernacular_name`, `taxon_distribution`, `taxon_species_profile`, `taxon_reference`, `taxon_types_and_specimen`, `taxon_resource_relationship`), com FK `taxonID` e colunas nomeadas pelos termos DwC/GBIF da extensão — mais fiel à estrutura real do DwC-A e consultável com SQL comum (join), sem depender de tipos aninhados específicos de um motor. A lógica de deduplicação/mesclagem já validada por testes (ex.: `normalizeDistribution`) é preservada; ela passa a preencher as linhas dessas tabelas em vez de um subdocumento Mongo.
